# Sentiment Analysis App

This project is a **Sentiment Analysis Web App** built using **Python, Transformers, and Gradio**.

## 🚀 Features

* Predicts whether text sentiment is **Positive, Negative, or Neutral**
* Uses pretrained NLP models from Hugging Face
* Interactive web interface using Gradio

## 🛠️ Tech Stack

* Python
* Transformers
* PyTorch
* Gradio

## ▶️ How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the app

python app.py

## 📊 Example Input

"I love this product, it works perfectly!"

Output: **Positive Sentiment**
